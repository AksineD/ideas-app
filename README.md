# ideas-app

Статичный веб-интерфейс для приватного репозитория идей (канбан, «Что дальше», «Залежалось», добавление идей и заметок).
Здесь только код: данных нет. Репозиторий и токен вводятся в браузере и хранятся в localStorage.

Токен: GitHub → Settings → Developer settings → Fine-grained tokens, доступ только к репозиторию с идеями, Contents: Read and write.
